# Email Application Program

A simple Java console-based Email Application Program built as a beginner Java project.

The application demonstrates fundamental Java programming concepts such as classes, objects, constructors, methods, encapsulation, user input, and basic application logic.


## Features

- Create an email account
- Capture employee/user information
- Generate an email address
- Generate and manage a password
- Set an alternate email address
- Set and display mailbox capacity
- Change password
- Display account information

## Technologies Used

- Java
- Maven
- IntelliJ IDEA / VS Code
- Git
- GitHub
